# Rescue on Fractalus! — Atari 8-bit → Amiga reimplementation

Reimplement the 1985 Lucasfilm Games title *Rescue on Fractalus!* on the Amiga
by reverse-engineering the Atari 8-bit binary (`rof.xex`), converting the 6502
machine code to portable C, abstracting all hardware access behind a platform
layer, and implementing that layer for SDL (development/verification on macOS)
and then the Amiga.

This mirrors the approach previously used to port *Attack of the PETSCII Robots*
(C64 → Amiga) and to improve *Stunt Car Racer* (68000), adapted for the fact
that we start from a binary only — everything begins with a decompilation.

## The source binary

`rof.xex` — 43,066 bytes, a standard Atari 8-bit XEX (segmented load file).
It is a **64K XL/XE** program (it pokes PIA `PORTB`/`$D301` for memory
management). The loader runs in four stages via `INITAD` (`$02E2`) vectors;
the final entry point is **`$3CDE`**. The bulk of the game is one ~31.5 KB
code+data block at `$3CDE–$B7FF`. See `tools/xex_map.py` output for the full
segment table.

## Approach / pipeline

Because the target is a faithful 1:1 port and we convert to C before fully
understanding the code, the first C pass is a **mostly-mechanical
transliteration** (a static recompilation): every 6502 instruction maps to a C
statement operating on emulated registers (`A/X/Y/S/P`) and a real 64K memory
array, with `JSR`→call, branches→`goto`, and RAM vs. hardware access split at a
memory bus. A literal translation is faithful by construction; we then refactor
toward idiomatic, named, documented C as understanding grows (the "rename in C"
step). A shared **symbol map** drives both the disassembly annotations and the
C generator, so a name learned once propagates everywhere.

```
rof.xex
  └─ tools/xex_load.py ──► disasm/rof_mem.bin  (post-load 64K image) + entry vectors
        └─ Ghidra headless (ghidra_scripts/) ──► disasm/listing.txt, xrefs, hw-access map
              └─ disasm/symbols.csv  ◄── shared, grows over time (addr → name/type/is_hw)
                    └─ tools/transpile.py ──► src/gen/*.c   (transliterated 6502)
                          ├─ src/cpu/      6502 register/flag model + memory bus
                          ├─ src/platform/ platform.h abstraction API (hardware boundary)
                          └─ src/backend/{sdl,amiga}/  concrete implementations
                                └─ builds & runs: SDL on macOS first, then Amiga
```

Phase 1, first task: generate the **hardware-access map** — a headless Ghidra
cross-reference dump of every access to `$D000–$D7FF` (GTIA/POKEY/PIA/ANTIC) and

us exactly what `platform.h` must expose.
